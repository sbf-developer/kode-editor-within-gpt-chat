# Instructions for assistants

## Purpose

This repository stores the reusable offline code editor in `CS50_Editor.html`.
Read `README.md` before helping a user reuse it.

## Reusing the editor in ChatGPT

- Retrieve the existing HTML file; preserve its functionality instead of replacing it with a basic textarea.
- Offer it as a downloadable HTML file or an interactive preview when the current interface supports one.
- Do not claim that this repository installs a native ChatGPT sidebar, opens Canvas, or grants access to unsent editor content.
- A separate browser window beside the chat is the supported independent workflow.
- **Copy answer** must copy only source text. Never substitute an image, screenshot, rendered editor page, or line-number text.
- During practice, give one small problem at a time and accept code, pseudocode, or a mix. Review submitted attempts; do not fill in solutions unless requested.
- Preserve the user's current attempt when updating their editor. Use an unimplemented starter when starting a new exercise.

## Maintenance

- Keep the delivered HTML self-contained and usable offline.
- Preserve local draft saving, keyboard editing, language selection, and clipboard fallbacks.
- Keep CodeMirror copyright and MIT license notices when redistributing its code.
- Avoid publishing personal draft content or browser storage.
- Verify JavaScript syntax after code changes. For interaction changes, verify the affected controls when a browser is available.
- Keep claims accurate: syntax highlighting is not compilation or code execution.
